## 🧠 我对 AI 应用层的思考

<div align="center">

<img src="https://readme-typing-svg.demolab.com?font=JetBrains+Mono&weight=500&size=14&duration=2800&pause=500&color=F472B6&background=00000000&center=true&vCenter=true&width=800&height=30&lines=%E4%B8%8D%E6%98%AF%E2%80%9C%E4%BC%9A%E8%B0%83+API%E2%80%9D%EF%BC%8C%E8%80%8C%E6%98%AF%E2%80%9C%E8%83%BD%E6%8A%8A%E6%A6%82%E7%8E%87%E7%A8%8B%E5%BA%8F%E5%B7%A5%E7%A8%8B%E5%8C%96%E2%80%9D" alt="sub" />

<br/>

<img src="https://media.giphy.com/media/LaVp0AyqR5bGsC5Cbm/giphy.gif" width="120" alt="thinking" />

</div>

<table>
<tr>
<td width="50%" valign="top">

### 🧩 Context Engineering > Prompt Engineering

2026 年还在调单条 Prompt 已经过时。真正决定 Agent 表现的是**上下文窗口里塞了什么、什么时候塞、塞多久**：

- **分层 Prompt**：System / Tools / Memory / Retrieval / User Turn 拆开管理
- **Prompt Caching**：Anthropic / OpenAI 的 cache 命中率直接决定成本曲线
- **上下文压缩**：长会话用摘要 + 关键事实表，而不是无脑 truncate
- **失败回放**：每条线上 trace 都是下次 Few-shot 的素材库

</td>
<td width="50%" valign="top">

### 🧪 Eval-Driven Development（EDD）

> _"If you can't measure it, you can't ship it."_

我把 LLM 应用当成**概率程序**来工程化：

- 上线前先有 **golden set + LLM-as-Judge 矩阵**
- 每次 Prompt / 模型 / 检索改动都跑 **promptfoo 回归**
- CI 里挂 **Ragas / DeepEval** 阈值，不达标不合并
- 线上 **Langfuse 采样回流** → 自动扩充 eval 集

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🔍 Agentic RAG，而不是 Vanilla RAG

朴素「Embedding 一把梭」的时代结束了。我的默认配方：

- **Query Rewriting / HyDE** 让检索 query 更接近文档分布
- **Hybrid（BM25 + Dense + Rerank）** 召回兜底
- **GraphRAG / 知识图谱** 处理跨文档的多跳推理
- **Agentic Loop**：Agent 自己决定要不要再查、查什么、何时停

</td>
<td width="50%" valign="top">

### 🛰️ AI Gateway 不是奢侈品

任何严肃的 AI 产品都需要一层网关：

- **多模型路由**：DeepSeek / Claude / GPT / Qwen，按任务/成本切
- **Fallback & Retry**：429 / context overflow 自动降级
- **Token 预算 & 限流**：单用户、单租户、单链路三级
- **Inference-Time Scaling**：高价值任务跑 best-of-N / self-consistency

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🌊 Streaming-First & Generative UI

LLM 产品的 UX 不是"等几秒看结果"，而是**让用户和 token 一起呼吸**：

- **SSE / WebSocket** 全链路流式，第一个 token < 800ms
- **Generative UI**：模型直接产出可交互组件（卡片、表单、图表）
- **Tool-Use 可视化**：让用户看到 Agent 在调什么工具、在想什么
- **可中断 / 可纠正**：Human-in-the-loop 是默认、不是补丁

</td>
<td width="50%" valign="top">

### 🔐 Guardrails 是产品功能，不是补丁

合规、越狱、隐私、幻觉，必须在架构里就有位置：

- **输入侧**：PII 脱敏、注入检测、意图分类
- **输出侧**：JSON Schema 强约束 + 重试、敏感词、引用核查
- **Agent 侧**：工具白名单、副作用确认、最大步数 / 预算阈值
- **审计侧**：每一步 trace 落库可回放、可追责

</td>
</tr>
</table>
